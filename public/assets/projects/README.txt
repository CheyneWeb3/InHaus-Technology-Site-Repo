PROJECT IMAGE FOLDER

Add your real project and game screenshots here, then set the path in public/projects.json.

Example:
  "image": "assets/projects/foxyswap.webp",
  "imageAlt": "FoxySwap Trade application screen",
  "imageFit": "cover",
  "imagePosition": "center"

Gallery example:
  "gallery": [
    {
      "src": "assets/projects/foxyswap-route.webp",
      "alt": "FoxySwap route detail screen",
      "caption": "Route and execution detail"
    }
  ]

Blank image and gallery fields remain image-free. The site does not generate or substitute project artwork.
