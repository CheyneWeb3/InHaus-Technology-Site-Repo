# SEO and social sharing

Production domain: `https://inhaus.technology/`

Included in the built `dist/`:

- Canonical URL and index/follow robots directive
- Full Open Graph metadata
- X/Twitter `summary_large_image` metadata
- 1200 × 630 branded PNG social card
- Open Graph image dimensions, type and accessible alt text
- Organization, WebSite, WebPage and JSON-driven ItemList structured data
- `robots.txt` with absolute sitemap location
- `sitemap.xml`
- Web app manifest
- SVG, ICO, PNG and Apple Touch icons
- Content-hashed production CSS and JavaScript

The project catalogue remains controlled only by `public/projects.json`. The build generates the structured project list from that file, so SEO project ordering follows the same `order` values shown on the site.
